# Artefacto Rive

`teams4soft-tess.riv` es una **copia** del build de diseño.

- Fuente: `tess-rive/` en la raíz del repo (proyecto del editor Rive).
- Comando de actualización: `pnpm --filter @teams4soft/tess-rive sync:riv`

No edites este archivo a mano. Si `scene.rml` cambia los nombres del artboard,
la state machine o los inputs, actualiza también `src/contract.ts`.
